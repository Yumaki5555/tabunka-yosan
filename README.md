# 全国 多文化共生予算マップ

あなたの自治体は、何にいくら使っている？
全国の都道府県・市区町村が、外国人住民や外国人に関係する施策に「何に、いくら使っているか」を、予算書・決算書などの公式資料から調べて比べられるサイトです。行政が「多文化共生」と呼ぶ事業だけでなく、外国人への給付・生活支援・教育・医療・福祉・通訳・行政対応なども調べます。

- 公開先：https://yumaki5555.github.io/tabunka-yosan/ （リポジトリ Yumaki5555/tabunka-yosan、main の / を GitHub Pages で公開）
- 政策への賛成・反対を示すものではありません。数字は公式資料で確かめたものだけを載せ、未調査・資料未発見・金額非公表・0円を区別します。
- 事業は「誰を対象に、何のために使うお金か」で①〜⑤に分けます（基準は [docs/分類と集計の基準.md](docs/分類と集計の基準.md)）。基本集計（外国人関連予算）＝①外国人等への直接給付・支援＋②外国人対応の行政経費＋③一般事業のうち外国人関連部分の金額が資料で分かった分。④関連事業・参考経費と⑤対象外は足しません。

## データを足す・直すとき

調査の手順書・作業メモ・点検の結果は公開しません（このリポジトリの外の、管理用の非公開フォルダに置いています）。CSV は誰でも見られるので、文章の欄には調査結果・金額の根拠・未確認の範囲だけを書きます（サーバーの制限・道具の名前・資料の取り方などの作業メモがあると、`node tools/build.mjs` がエラーにして公開用データを作りません）。おおまかな流れは次のとおりです。

1. 公式資料を調べて、CSV（またはJSONの調査票）に記入する
2. `node tools/build.mjs` で点検し、公開用データを作る（エラーがあると作りません）
3. `python -I tools/fetch_sources.py <作業用フォルダ>` と `python -I tools/verify_pages.py <作業用フォルダ>` で、金額が資料の掲載ページに本当にあるか照合する
4. 照合できた行だけ「確認」を「確認済み」にして、もう一度 `node tools/build.mjs`
5. GitHub に上げる（JS・CSSを直したときは、先に `python tools/set_version.py`）

## プログラム（tools/）

| コマンド | すること |
|---|---|
| `node tools/build.mjs` | CSVを点検（形式・重複・つながり・金額と単位・財源の合計・公開する文章に作業メモがないか）し、自治体×年度×段階ごとに事業別の内訳と合計が一致するかを検算して、`data/dist/` を作る（点検の結果は公開しない `tools/build_report.local.json` に書く） |
| `node tools/test_site.mjs` | 点検と集計の決まりのテスト |
| `node tools/import_research.mjs 調査票.json` | 調査票（JSON）をCSVに変える（取り込んだ金額は「要確認」になる。調査メモは CSV に入れず非公開フォルダに書く） |
| `python -I tools/fetch_sources.py <フォルダ>` | 出典URLから資料を取ってくる（リンク切れの確認にもなる） |
| `python -I tools/verify_pages.py <フォルダ> [--render <フォルダ>]` | 金額と記載が資料の掲載ページにあるか照合し、`tools/verify_report.csv` に書く |
| `python tools/make_master.py` | 自治体マスタ・人口・地図の形を作り直す（「数でみる在留外国人」の作業フォルダが必要） |
| `python tools/set_version.py` | 見る人のブラウザに古いJS・CSSが残らないよう版番号を付ける |
| `python tools/serve.py` | 確認用のサーバー（http://127.0.0.1:8781/ ） |

## 出典・利用の条件

- 金額：各自治体の予算書・予算の概要・決算書・主要施策の成果などの公式資料（事業ごとに資料名・URL・掲載ページを記録）
- 自治体の一覧：総務省「全国地方公共団体コード」（令和6年1月1日現在）
- 人口：総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」（e-Stat）を加工して作成
- 外国人住民数：出入国在留管理庁「在留外国人統計」（e-Stat）を加工して作成
- 地図：国土地理院「地球地図日本」（第2.1版 行政界、https://www.gsi.go.jp/kankyochiri/gm_jpn.html ）を加工して作成（国土地理院コンテンツ利用規約による）
