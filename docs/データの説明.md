# データの説明

各表の列の意味です。CSVの1行目には「列の名前」をそのまま書きます。文字コードは UTF-8（Excel では「CSV UTF-8」で保存）。

金額はすべて円（整数）で書き、資料に書かれていた数字と単位も「資料の数字」「資料の単位」に残します。キーは、自治体コード（6桁の全国地方公共団体コード）・年度（西暦）・事業IDです。

CSV は公開しているので、文章の欄（事業内容・分類の理由・備考・調べた範囲など）には、調査結果・金額の根拠・未確認の範囲など、利用する人に必要なことだけを書きます。資料の取り方や作業の手順などの作業メモは書きません（書くと `node tools/build.mjs` がエラーにします）。

## 一般会計の予算総額（data/general/）

自治体×年度×段階ごとに1行。その自治体の一般会計の予算の総額（特別会計・企業会計を含まない）を、自治体の予算書などの公式資料から写します。「一般会計に占める割合」の分母に使います。行がない組み合わせは「未確認」です（割合を出しません）。

| 列 | 必須 | 書き方 |
|---|---|---|
| 自治体コード | 必須 | 6桁 |
| 年度 | 必須 | 西暦4桁 |
| 段階 | 必須 | 当初予算・補正後予算・決算（多文化共生関連予算と同じ段階どうしで割り算する） |
| 一般会計の総額（円） | 必須 | 円に直した整数 |
| 資料の数字 | 必須 | 資料に書かれたとおり（例：123,456,789／1兆658億5,189万8千） |
| 資料の単位 | 必須 | 円・千円・万円・百万円・億円 |
| 出典ID | 必須 | その自治体自身の資料（出典資料の表に登録） |
| 掲載ページ | 必須 | 例：PDFの5ページ目 |
| 資料の記載 |  | 総額が書かれた文を原文どおり（例：第1条 歳入歳出予算の総額は、歳入歳出それぞれ…千円と定める） |
| 確認 | 必須 | 確認済み・要確認（要確認の行は割合の計算に使わない） |
| 確認日 | 必須 | 2026-02-13 の形 |
| 備考 |  | 骨格予算・議会での修正など、比べるときに知っておくべきこと |

一般会計に占める割合 ＝ 基本集計のうち会計が「一般会計」の事業の金額 ÷ 同じ自治体・同じ年度・同じ段階の一般会計の総額。計算は `assets/js/calc.js` の `ratioOf`（画面と `tools/build.mjs` の検算が同じ関数を使う）。
