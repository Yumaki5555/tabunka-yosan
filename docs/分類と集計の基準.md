# 分類と集計の基準（2026年10月29日から）

このサイトで知りたいのは、行政が「多文化共生」と呼ぶ施策の予算だけではありません。
**自治体が、外国人住民や外国人に関係する施策に、どれくらいの予算を計上しているか**です。

そのため、事業を「多文化共生施策かどうか」ではなく、**誰を対象に、何のために使うお金か**で分けます。
そして、次の原則を守ります。

> **関係する事業は広く拾う。ただし、基本集計に加える金額は、資料で根拠を確かめられたものに限る。**

この基準は、新しく登録する事業だけでなく、登録済みのすべての事業に当てはめます。

---

## 1. 5つの分類

| 分類 | 名前 | 基本集計 |
|---|---|---|
| ① | 外国人等への直接給付・支援 | 原則として事業の金額を入れる |
| ② | 外国人対応の行政経費 | 原則として事業の金額を入れる |
| ③ | 一般事業に含まれる外国人関連経費 | 外国人関連の部分の金額が資料にあるときだけ、その部分を入れる |
| ④ | 関連事業・参考経費 | 入れない（事業全体の金額を参考として記録） |
| ⑤ | 対象外 | 入れない |
| 別枠 | 学校の教員の人件費、中国残留邦人等・引揚者などの援護 | 入れない（①〜⑤とは別の枠。事業の金額は参考として別に示す。2026年10月30日から） |
| 保留 | 判定保留 | 入れない（判定に必要な情報が足りず、追加の調査が必要） |

**基本集計（多文化共生関連予算。以前の画面では「外国人関連予算」）＝ ①の金額 ＋ ②の金額 ＋ ③のうち外国人関連の部分の金額（資料で分かった分）**

①と②は別々にも数えます。①は外国人本人に届く給付・支援、②は行政が外国人に対応するために使う経費です。
①には現金の給付だけでなく、日本語教室や学校での日本語指導のようなサービスも入ります。**①の金額がすべて外国人個人に支払われるわけではありません。**

### ① 外国人等への直接給付・支援

外国人住民などを対象として設けられた給付金・補助金・支援事業。

| 類型 | 中身 | 例 |
|---|---|---|
| 1-給付金 | 外国人への福祉給付金 | 外国人高齢者・障害者福祉給付金（国籍要件のため年金を受けられない人への給付）、特別永住者福祉給付金 |
| 1-日本語 | 大人の日本語学習 | 日本語教室・講座、講師やボランティアの謝礼・養成、地域日本語教育の体制づくり |
| 1-子ども | 外国人の子どもの教育支援 | 日本語指導、日本語指導員・支援員、初期指導教室、就学・進学の支援、プレスクール、母語支援 |
| 1-学校・留学生 | 外国人学校・留学生への支援 | 外国人学校やその児童生徒・保護者への補助、外国籍生徒の授業料支援、留学生の奨学金・宿舎・生活支援 |
| 1-生活 | 暮らしの支援 | 避難民への生活支援金・住まい、居場所づくり、子育て支援、個別の伴走支援、外国人向けの防災・交通安全・消費生活の講座 |
| 1-就労 | 就労・定着の支援（本人向け） | 外国人労働者・外国人材本人への日本語学習・資格取得・研修・就職相談・定着支援 |
| 1-医療福祉 | 医療・保健・福祉（本人向け） | 外国人を対象とする健診（日本語学校の留学生の結核健診など）・医療・福祉サービス |

学校の教員（教職員定数で置く教員）の人件費と、中国残留邦人等とその家族への日本語教育・地域生活支援は①に入れず、別枠にします（下の「別枠」）。

帰国児童生徒・帰化した人など、**日本国籍の人も対象に含まれる事業は、そのことを「対象者の範囲」に書きます**。外国籍の人だけに使われる予算だと受け取られないようにするためです。

### ② 外国人対応の行政経費

外国人住民などに行政サービスを届けるため、または外国人の受入れのために行政が使う経費。

| 類型 | 中身 | 例 |
|---|---|---|
| 2-通訳翻訳 | 通訳・翻訳 | 通訳者の派遣・委託、電話・映像通訳、翻訳、翻訳機・翻訳システム（窓口・学校・医療・警察・消防・119番など） |
| 2-相談 | 外国人相談 | 外国人相談窓口・一元的相談窓口・外国人相談員 |
| 2-情報 | 多言語の情報提供 | 外国人向けの生活ガイド、多言語のホームページ・SNS、防災情報、行政案内 |
| 2-研修 | 職員・支援者の研修 | やさしい日本語・多文化共生の職員研修、通訳ボランティアや災害時の外国人支援者の養成 |
| 2-企画 | 外国人施策の企画・推進 | 多文化共生の計画づくり、外国人住民の実態調査、審議会・会議・協議会、担当職員の人件費・事務費 |
| 2-啓発交流 | 共生の啓発・地域づくり | 外国人住民と日本人住民の相互理解のための啓発・交流行事・地域づくり（外国人住民を対象または前提とすると資料に書かれているもの） |
| 2-受入れ | 受入れ環境の整備 | 外国人材を受け入れる企業・介護施設・医療機関への支援、外国人患者の受入れ体制、外国人の未払医療費の補助、受入れの協議会・セミナー |
| 2-海外確保 | 海外からの人材確保 | 送り出し国との関係づくり、海外での説明会・募集、来日前の研修の支援、留学生の誘致 |
| 2-拠点 | 外国人支援の拠点施設 | 多文化共生センター・外国人総合相談センターなど、外国人支援が主な目的の施設の運営 |
| 2-協会事業 | 使い道を限った協会への補助・委託 | 国際交流協会などへの補助・委託のうち、使い道が外国人支援・多文化共生の事業に限られたもの |
| 2-法定事務 | 外国人に関する法定の事務 | 在留カードの住居地届出など、国から任された事務の経費 |
| 2-指導 | 外国人に関する指導・徴収など | 不法就労の防止、生活ルールの指導・巡回、外国人の保険料の未納対策 |

通訳・翻訳の利用者に日本国籍の人が含まれることがあります（外国語を使う人なら国籍を問わない）。その場合は「対象者の範囲」に書き、外国籍の人だけの経費とは言いません。

### ③ 一般事業に含まれる外国人関連経費

一般の住民も対象とする事業の一部に、外国人関連の経費が含まれるもの。中身は①や②と同じ種類（類型は①②の名前を使います）ですが、**記録した金額が一般事業全体の金額**であるものです。

- 外国人関連の部分の金額が資料にあれば、**その部分だけ**を基本集計に入れます（「うち外国人関連」の列）。
- 部分の金額が資料になければ、事業全体の金額を**参考として記録し、基本集計には入れません**。
- 人口や外国人住民の割合などで、根拠なく按分（割り算で配分）しません。

例：広報紙の発行（うち多言語版の作成費）、ホームページの運営（うち自動翻訳）、夜間中学、識字・日本語学級、字幕表示システム（聴覚障害のある人と外国人の両方向け）、一般の相談窓口（外国人相談を含む）、介護人材の確保（外国人材の分を含む）、人権啓発（外国人の人権を含む）

### ④ 関連事業・参考経費

外国人施策や国際交流に関係はあるが、外国人住民などへの支出として金額を特定できない事業。**事業全体の金額は記録しますが、基本集計には入れません。**
使い道の内訳から外国人支援・外国人対応の金額が分かれば、その部分を①②③に移して数えます。

| 類型 | 中身 | 例 |
|---|---|---|
| 4-協会運営 | 国際交流協会などの運営補助 | 使い道の内訳がなく、国際交流など外国人支援以外の事業も含む補助・助成・負担金 |
| 4-施設 | 国際交流施設の管理 | 国際交流センター・会館などの施設全体の管理運営・指定管理・整備 |
| 4-国際交流 | 国際交流・海外交流 | 姉妹・友好都市交流、大使館などとの交流、海外派遣、国際協力、国際会議への参加、国際交流基金への積立 |
| 4-JET | 国際交流員などの招致・国際化協会 | 国際交流員（CIR）などJETプログラムの招致、自治体国際化協会への分担金・負担金 |
| 4-複合 | 国際交流と一体の事業 | 国際交流・国際化と外国人住民の支援を一体で行い、外国人住民の支援の分を切り分けられない事業 |
| 4-経済観光 | 経済・観光・誘致 | 外国企業・外国人起業家・インターナショナルスクールの誘致、訪日観光客の誘致、観光客向けの通訳・多言語案内・受入環境の整備（観光客向けの多言語コールセンター・観光案内所・多言語の案内表示など）、海外への売り込み |
| 4-その他 | その他の関連事業 | 上のどれにも当たらないが外国人施策に関係する事業 |

**国際交流そのものを、外国人住民の支援と同じものとは扱いません。**

### ⑤ 対象外

外国人との明確な関係が確認できない事業。外国人も住民として利用している、という理由だけでは数えません。

| 類型 | 中身 | 例 |
|---|---|---|
| 5-一般 | 一般の行政サービス | 外国人も使うだけで、外国人のための独立した経費が確認できない事業 |
| 5-国際 | 外国人と関係のない国際事業 | 国際理解教育、外国語指導助手（ALT）、日本人の海外留学・派遣 |
| 5-無関係 | 外国人と関係がない事業 | 手話通訳、「共生」が外国人と関係のない意味で使われている事業 |

外国人対応のための独立した追加経費が見つかったときは、その部分を①②③に分け直します。

### 別枠：合計に入れず別に示す経費

次の2つは、①〜⑤とは別の枠にし、**基本集計には入れません**。どれも実際に使われるお金なので、事業は見落とさないように登録して金額を記録し、自治体のページで「別枠」の金額として種類ごとに参考に示します。地図・ランキング・比較には入れません。

特定の自治体だけに「比べるときの注意」を付けて説明する方法はとりません。比べにくい経費は、全国で同じ決まりにそろえて別枠にします。

#### 学校の教員の人件費（2026年10月30日から）

学校に配置する教員（教職員定数で置く教諭・講師など。国の加配定数・基礎定数による日本語指導の担当教員や、自治体が独自に増やす加配の教員を含む）の給与・手当などの人件費は、別枠にします。

- 公立小中学校の教員の給与は、都道府県（政令指定都市の学校は市）が負担します。多くの自治体では、日本語指導を受け持つ教員の人件費も教職員の人件費全体にまとめて計上され、その部分の金額が予算資料にありません。金額が分かる一部の自治体だけ基本集計に入れると同じ条件で比べられなくなるため、**金額が資料で分かっても基本集計に入れません**。
- 日本語指導員・支援員・母語支援員・語学相談員・通訳など、**自治体が事業の費用で雇う人の報酬・謝礼や委託料**は、これまでどおり①〜③に分けます（教職員定数の教員ではなく、事業ごとに予算に計上されるため）。教員の研修・連絡協議会の費用も同じです。
- 1つの事業に教員の人件費とほかの経費がまざり、教員の人件費の金額を分けられないときは、主な中身で分類を決め、教員の人件費を含むことを「分類の理由」に書きます。

#### 中国残留邦人等・引揚者などの援護

中国残留邦人等への支援給付・援護、引揚者の援護、戦後補償の関係の事業は、戦争の影響を受けた人への援護（戦後処理）として国の制度にもとづいて行うもので、外国人向けの施策とは性格がちがいます。そのため別枠にします。

- 支援給付・配偶者支援金・支援相談員・援護の事務だけでなく、**中国帰国者とその家族の日本語教育・地域生活支援・自立支援通訳の派遣なども別枠**にします（中国残留邦人等の支援の一部として行われるため）。
- 制度の対象は中国残留邦人等（本人は日本国籍）とその配偶者・家族です。支援給付に国籍の要件はなく、外国籍の配偶者も対象になります（厚生労働省「中国残留邦人等に対する支援策に係る問答集」問25）。「対象者の範囲」にはそのことを書きます。
- 戦没者遺族の援護など、外国人と関係のない戦後処理の事業は登録しません。予算書の1つの事業に中国残留邦人等の援護と戦没者遺族の援護などがまざるときは、その事業を別枠で登録し、中身を「事業内容」に書きます。
- 別枠の事業の内訳を別の事業としても登録したときは、「金額が含まれる事業ID」に親の事業を書き、別枠の金額の合計でも二重に数えません。

| 類型 | 中身 | 例 |
|---|---|---|
| 別-教員 | 学校の教員の人件費 | 日本語指導を受け持つ教員の配置（日本語教育適応学級担当教員など）の給料・手当 |
| 別-援護 | 中国残留邦人等・引揚者などの支援給付・援護 | 生活支援給付・配偶者支援金、支援・相談員、援護の事務、引揚者等援護事務費 |
| 別-生活支援 | 中国残留邦人等の日本語・地域生活の支援 | 中国帰国者の日本語教室・地域生活支援プログラム・自立支援通訳の派遣、帰国者の団体への補助 |

帰国児童生徒（海外から帰国した日本国籍の子ども）への日本語指導や、夜間中学の日本語学級のように、中国残留邦人等の援護の制度ではない事業は、これまでどおり対象と目的で①〜⑤に分けます。

### 判定保留

対象・目的・中身が資料の記録から読み取れず、分類を決められない事業。**不明なものを④や⑤にまとめて入れず、保留にして追加で調べます。** 保留の事業は基本集計に入れません。

---

## 2. 分類を決める手順

1. **中身の類型を決める**：誰を対象に、何のために使うお金かを、資料に書かれた事業の目的・内容・予算書の項目名で判断する（事業名だけでは決めない）。
2. **金額の作りを確かめる**：記録した金額が、外国人関連のためだけの金額（独立した事業、または予算書の内訳の1行）か、一般事業全体の金額かを見る。
3. **分類を決める**：①②の類型で独立した金額 → ①または②。①②の類型で一般事業の一部 → ③。④⑤の類型 → ④または⑤。学校の教員の人件費、中国残留邦人等・引揚者などの援護 → 別枠。決められない → 保留。

1つの事業に①と②の中身がまざるときは、主な中身で決めます（どちらも基本集計に入ります）。国際交流（④）の中身が大きく、切り分けられないときは④（4-複合）にします。

### 迷いやすい事業のそろえ方

| 事業 | 分類 | 理由 |
|---|---|---|
| 外国人高齢者・障害者福祉給付金 | ① | 国籍要件のために年金を受けられない外国人への給付。帰化した人も対象のときは「対象者の範囲」に書く |
| 日本語指導を受け持つ教員の配置（教職員定数で置く教員の人件費） | 別枠 | 多くの自治体で教職員の人件費全体に含まれて金額が分からないので、金額が分かる自治体でも基本集計に入れない（全国で同じ条件にそろえる） |
| 学校の日本語指導員・支援員・語学相談員（自治体が事業の費用で雇う人の報酬・謝礼・委託） | ① | 外国人の子どもの教育支援。教員の人件費ではない |
| 中国残留邦人等の生活支援給付・配偶者支援金・支援相談員・援護の事務 | 別枠 | 戦争の影響を受けた人への援護（戦後処理）で、外国人向けの施策とは性格がちがう。基本集計に入れず、金額を参考として別に示す（「対象者の範囲」に「外国籍の住民・滞在者」も書く） |
| 中国帰国者とその家族の日本語教育・地域生活支援 | 別枠 | 中国残留邦人等の支援の一部として行われるため、給付と同じく別枠にする（対象者の説明に「本人は日本国籍」と書く） |
| 引揚者援護・戦後補償の関係の事業 | 別枠 | 外国人向けの施策としては数えない。外国人と関係のないもの（戦没者遺族の援護など）は登録しない |
| 外国人材の受入れ企業への支援・セミナー | ② | 外国人の受入れのための行政経費 |
| 外国人材本人への日本語・資格取得・定着の支援 | ① | 外国人本人への支援 |
| 海外での人材募集・送り出し国との関係づくり | ② | 外国人の受入れのための行政経費（以前は参考情報にしていた） |
| 警察・消防・119番の通訳 | ② | 外国語を使う人への行政対応 |
| 観光客向けの通訳・多言語案内（観光客向けの多言語コールセンター・観光案内所・多言語の案内表示・旅行者向けの多言語の啓発など） | ④ | 観光客の受入れのための観光施策で、外国人住民の支援ではない。警察・消防・119番・医療機関の通訳のように住民も観光客も使う行政サービスは② |
| 外国人の未払医療費の補助（医療機関へ） | ② | 外国人患者の受入れのための行政経費 |
| 日本語学校の留学生の結核健診 | ① | 対象が外国人留学生と特定された健診 |
| 国際交流協会の運営費補助（使い道の内訳なし） | ④ | 国際交流も含み、外国人支援の金額を特定できない |
| 国際交流協会への補助のうち「在住外国人支援事業分」など使い道が限られたもの | ② | 使い道が外国人支援に限られる |
| 国際交流センターの施設全体の管理 | ④ | 施設全体の経費。外国人支援の部分の金額が分かれば③ |
| 多文化共生センターなど外国人支援が主目的の施設 | ② | 施設の目的が外国人支援 |
| 国際交流員（CIR）の招致・自治体国際化協会の分担金 | ④ | 国際交流が中心で、外国人住民の支援の金額を特定できない |
| 外国語指導助手（ALT）・国際理解教育 | ⑤ | 日本人の子どもの外国語・国際理解の教育 |
| 夜間中学・識字学級 | ③ | 外国人の生徒が多いが、一般の学びの場。外国人の分の金額は分からない |
| インターナショナルスクールの誘致 | ④ | 経済施策としての誘致 |

---

## 3. 対象者の範囲

国籍・外国出生・外国にルーツがあること・外国語を使うことは、同じではありません。事業ごとに、次のどれに当たるかを記録します（複数あれば「;」で区切る）。

- 外国籍の住民・滞在者
- 外国出生者
- 帰化者・元外国籍者
- 外国にルーツがある人
- 外国人と日本人の双方
- 国籍を問わない外国語利用者
- 対象者の範囲が不明

「対象者の説明」の列に、資料にもとづく具体的な説明を書きます（例：日本語指導が必要な児童生徒。外国籍のほか、帰国児童生徒など日本国籍の子どもを含む）。

**基本集計に入ることと、その全額が外国籍の人に使われることは同じではありません。** 外国籍の人だけに実際に使われた金額が資料で分かるときは、予算の表の「うち外国籍の人だけへの支出（円）」に別に記録します。

## 4. 確認状況（分類とは別に管理）

| 確認状況 | 意味 |
|---|---|
| 確認済み | 対象・目的・金額が公式資料で確認できる |
| 一部確認済み | 事業の存在や予算は確認できるが、外国人関連の部分の内訳が分からない（③で部分の金額が不明、④、金額の記録がない①②） |
| 要確認 | 分類の判断に必要な情報が足りない（判定保留） |
| 調査未実施 | まだ十分に調べていない |

出典があっても、事業の目的や金額の根拠が確かめられないときは「確認済み」にしません。

## 5. 金額の区別

事業ごとに、次の3つを分けて扱います。

| 記号 | 金額 | 基本集計 |
|---|---|---|
| A | 事業全体の予算額（予算書などに書かれた事業の金額） | — |
| B | 外国人関連として確認できる予算額（①②の金額、③で部分が分かった金額） | **Bだけを足す** |
| C | 外国人関連の部分が分からない事業全体の予算額（③で部分が不明なもの、④）と、別枠の事業の予算額 | 足さない（参考） |

あわせて、次を守ります。

- 予算と決算を足さない。当初予算と補正後予算を分ける。補正予算は、増減額ではなく補正後の予算額を記録する（増減額しか分からないときはそのことを備考に書く）。
- 事業の金額と、その財源（国・都道府県の補助金など）を二重に数えない。財源は「財源の内訳」として示すだけ。
- 一般会計から特別会計への繰出金など、会計の間の重複を数えない。
- 同じ事業の再掲や、別の資料での重複登録を数えない。
- 金額が分からないものを0円として扱わない。
- 都道府県と市区町村の合計を足さない（県から市町村への補助が二重に数えられるため）。
- 前の年度との増減（自治体のページ・地図の色分け・ランキング・年度の比較）は、両方の年度を主な資料まで調べたとき（調査状況が「確認済み」か「該当事業なし」）だけ出す。一部の資料だけ調べた年度（「一部確認」）は、見つかって確かめられた事業だけの合計なので、調べた範囲の差で増減が実際より大きく見える。このため増減の金額・率や事業の新設・廃止を出さない。
- 前の年度との増減の率は、合計どうしではなく、両方の年度に基本集計の金額がある同じ事業（前身の事業IDでつないだ事業のまとまりを含む）どうしで計算する（calc.js の matchedPair、集計の ym）。片方の年度だけの事業（新しく始まった事業・終わった事業、前の年度の補正予算に前倒しして当初予算に載らなかった事業、片方の年度だけ金額が分かった事業）は、件数と金額を別に示す。合計どうしの差は参考として金額だけ示す。前倒しの補正予算は、その補正予算の年度・段階（補正後予算）に記録し、翌年度の当初予算には入れない（年度を混ぜない）。

### 財源

事業費と財源を分け、資料で確かめられたときだけ、国庫支出金・都道府県支出金・地方債・その他・一般財源を記録します。財源の内訳が分からないときに、推測で自治体の負担額を計算しません。自治体どうしを比べるとき、事業予算の総額と自治体の負担額を同じ物差しとして扱いません。

## 6. 一般会計に占める割合（2026年10月29日から）

**一般会計に占める割合 ＝ 基本集計（多文化共生関連予算）のうち一般会計の事業の金額 ÷ 同じ自治体・同じ年度・同じ段階の一般会計の予算総額 × 100**

- 分母は、自治体の公式資料（予算書の第1条「歳入歳出予算の総額は…」、予算に関する説明書の総括、予算の概要の会計別の表など）に書かれた一般会計の総額（data/general/）。特別会計・企業会計・全会計の合計は使わない。
- 分子は、基本集計の事業のうち「会計」が一般会計の事業だけ。資料に「○○特別会計」「○○事業会計」と書かれた事業（国民健康保険・介護保険の特別会計の多言語対応など）は分子に入れない。資料の事業の記載に特別会計・企業会計の表示がない事業は一般会計とする（款が総務費・民生費・教育費などの事業、一般会計予算書・一般会計の説明書に載っている事業を含む）。
- 分子と分母は同じ自治体・同じ年度・同じ段階（当初予算どうし）。補正予算・補正後予算・決算と混ぜない。都道府県と市区町村はそれぞれ自分の一般会計で割る。
- 一般会計の総額が未確認の年度は割合を出さない（「未確認」）。会計が分からない事業が1つでもある年度は「算出不可」。未調査・資料未発見などの自治体は0%にしない。
- 一部の資料だけ調べた自治体の割合は「確認済み分の割合」と表示する。ランキングは初めは「主な資料を調査済み」の自治体だけを並べる。

## 7. 各事業に残す記録

自治体名・年度、正式な事業名、担当部署、事業全体の予算額、基本集計に入れる金額、分類（①〜⑤・別枠・保留）、類型、会計（①②③の事業）、分類の理由、対象者の範囲と説明、出典（資料名・URL・掲載ページ）、確認状況、判定日。
